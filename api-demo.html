CloudGate API Demo

One HTML file, no build step - exercises every endpoint in API_DOCS.md against a live deployed CloudGate client. Open this file directly (double-click it) - CORS is enabled on the API so it works from file:// too.

Account

GET /api/profile · GET /api/stats · GET /api/quota
Stats and quota are computed by walking every category (built-in and custom) - CloudGate's own metadata service only knows its seven built-in folders, so anything in a custom category like 100gig-strg is counted here but wouldn't show in CloudGate's native totals.

Files - upload

  
POST /api/upload/multipart/create · complete · abort · POST /api/upload/presign · POST /api/upload

  

    
    
    
  

  

    
    
    
  

  

    

    

  

  

    The auto path is what the app uses. Files over 6 MB are split
    into 6 MB parts and uploaded 6 at a time in parallel straight
    to S3 (create → parallel PUTs → complete), then the server
    finalizes by reading each part's ETag with ListParts - so the
    browser never needs the ETag response header (which cross-origin CORS may
    hide). Several streams at once is dramatically faster when a single
    connection is throttled below your available uplink. Smaller files take
    the single presigned PUT. The via-server route buffers the whole file in
    the function's memory and fails on anything large - kept only for contrast.

Download & stream links

  
GET /api/download?key= · GET /api/stream/<filename>?key=

  

    
    
  

  

  

    Both links open fine when pasted into a new tab. Don't wire these to a
    script-triggered window.open() for media files though -
    Chrome downloads instead of playing/displaying them when the tab is
    opened programmatically rather than by a real navigation. Copy the link
    and open it yourself instead.

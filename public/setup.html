CloudGate Client setup

Three steps. Everything runs in your browser — nothing is uploaded.

Step 1

Run the script & copy your setup code

  1. Open the CloudGate web app in another tab and sign in.
  2. There, open DevTools → Console (F12).
  3. Click Copy script, paste it into that console, press Enter.
  4. It copies a single setup code to your clipboard. Come back here.
Reads your own logged-in session & sends nothing anywhere. 

  


  
  

    
Step 2

    
Paste it, then pick a username & password

    
Paste the setup code — it fills in your email, refresh token and access key
    automatically. Then all you choose is the login for this app.

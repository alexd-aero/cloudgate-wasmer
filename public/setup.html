CloudGate Client · Setup

Self-host your own CloudGate storage on Wasmer Edge

Five steps, ~10 minutes. Everything below runs in your browser and connects to your CloudGate account — nothing is uploaded to this server.

1

Fork the repo & make it private

You'll commit your credentials into this repo, so it must be private. Forks start public and can't be flipped to private until they leave the fork network first.

Fork alexd-aero/cloudgate-wasmer
  1. Fork it to your account (button above).
  2. In your fork: Settings → General → Danger Zone → Leave fork network — this detaches it so it can be made private.
  3. Wait for the detach to finish — GitHub processes it in the background, usually 2+ minutes. The repo may 404 briefly; that's normal.
  4. Once done: Settings → General → Danger Zone → Change repository visibility → Private.
Don't add your credentials (Step 4) until the repo is private. A public repo with them in it hands over your CloudGate account.
Prefer not to wait on detachment? Instead create a fresh private repo and push these files into it — no fork network to leave.
2

Run the script, copy your setup code

This grabs your CloudGate token from the session you're already signed into and packs it into one code — nothing leaves your browser.

  1. Open the CloudGate web app in another tab and sign in.
  2. There, open DevTools → Console (press F12).
  3. Click Copy script, paste into that console, press Enter.
  4. A Copy setup code button appears on the page — click it, come back here, and paste in Step 2.
